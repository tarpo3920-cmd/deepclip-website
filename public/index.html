🔑 API Setup Guide

DeepClip Backend အတွက် API Key များကို အောက်ပါ Website များမှ Account ပိုင်ရှင်က ထုတ်ယူနိုင်ပါတယ်။ API Key ကို ဒီ Website ထဲမှာ မထည့်ပါနဲ့။

1. OpenAI API Key
Video အသံကို စာသားပြောင်းခြင်းနဲ့ AI Recap ဖန်တီးခြင်းအတွက်
OpenAI API Keys ထုတ်ရန် ↗
2. GitHub Personal Access Token
KPay QR ပုံကို GitHub Repository မှာ သိမ်းရန် အသုံးပြုပါက လိုအပ်နိုင်ပါတယ်။
GitHub Token ထုတ်ရန် ↗
3. Render Environment Variables
Backend ရဲ့ Secret Key နဲ့ API Key များကို ဒီနေရာမှာ ထည့်ပါ။
Render Dashboard ဖွင့်ရန် ↗
  1. Render Dashboard ကို ဖွင့်ပါ။
  2. DeepClip Backend Web Service ကို ရွေးပါ။
  3. Environment ကို ဝင်ပါ။
  4. Add Environment Variable ကိုနှိပ်ပါ။
  5. အောက်က Key နဲ့ Value တွေကို သက်ဆိုင်ရာအတိုင်း ထည့်ပါ။
  6. Save Changes လုပ်ပြီး Deploy ပြီးအောင် စောင့်ပါ။

လိုအပ်နိုင်သော Environment Variable များ

OpenAI OPENAI_API_KEY = သင်၏ OpenAI API Key OPENAI_TRANSCRIBE_MODEL = whisper-1 OPENAI_TEXT_MODEL = gpt-4.1-mini
Security SECRET_KEY = လုံခြုံသော Random Secret ADMIN_EMAIL = သင်၏ Admin Email ADMIN_PASSWORD = ခိုင်မာသော Admin Password
GitHub QR Storage သုံးထားပါက GITHUB_TOKEN = GitHub Token GITHUB_REPOSITORY = username/repository GITHUB_BRANCH = main
Optional Settings MAX_UPLOAD_MB = 500 STARTER_CREDITS = 3
လုံခြုံရေးအတွက် API Key၊ GitHub Token၊ Admin Password တို့ကို HTML၊ JavaScript၊ GitHub Public Repository ထဲ မထည့်ပါနဲ့။ ဒီနေရာမှာလည်း Key အစစ်ကို မရိုက်ထည့်ပါနဲ့။ Account နဲ့ Billing ကို Account ပိုင်ရှင် သို့မဟုတ် တာဝန်ရှိသူက စီမံပါ။
